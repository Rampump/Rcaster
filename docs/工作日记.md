  - 源 Caster A 通过 NTRIP 上传 RTCM3 1005+1074；
  - A 写 etcd `runtime/sources/C66` 并进入 ACTIVE；
  - 边缘 Caster B 的 `SourceWatcher` 收敛到本地内存快照；
  - B 不拥有、不承接该源，但客户端连接 B 请求 `GET /` 时，B 从本地快照生成
    sourcetable 并返回 `STR;C66`。
  这证明客户端 STR 请求位于数据面本地路径，不是每个请求直连 etcd。
